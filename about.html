🐔 POULTRY HOUSE SMART MONITORING

Smart Poultry House Monitoring System

An IoT-based real-time monitoring platform for poultry houses. Sensor data is collected by an ESP32 microcontroller, pushed to Firebase Realtime Database every 10 seconds, and displayed live on this web dashboard — accessible from anywhere with an internet connection.

Version 1.0  ·  2026

🔌 Hardware Sensors

  • 🌡
    DHT22
    AM2302 — GPIO 27
    Measures ambient temperature (°C) and relative humidity (%). Requires a 10kΩ pull-up resistor on the DATA line to 3.3V.
  • ⚖️
    HX711 + Load Cell
    24-bit ADC — GPIO 4 (DT) · GPIO 5 (SCK)
    Measures feed hopper weight in grams using a 50 kg strain gauge load cell. Calibration factor: 2280.0 (adjustable in firmware).
  • 💡
    MH-Sensor (Photosensitive)
    LDR module — GPIO 34 (AO) · GPIO 26 (DO)
    Reports light brightness as a percentage (0 = dark, 100 = bright). DO pin provides instant hardware threshold switching via onboard potentiometer.
  • 💡
    Indicator LED
    GPIO 2 — via 200Ω series resistor
    Turns ON automatically when the house is dark (controlled by MH-Sensor DO pin). State is logged to Firebase on every push cycle.

🔥 Firebase Data Paths

All data is pushed to Firebase Realtime Database every 10 seconds. Push keys encode the exact timestamp — no separate time field needed.

  • /data/temperature float · °C · DHT22
  • /data/humidity float · % · DHT22
  • /data/weight float · g · HX711
  • /data/light int · % brightness · MH-Sensor
  • /data/led_status bool · LED on/off

✅ System Features

  • ✔Real-time sensor monitoring — updates every 10 seconds
  • ✔Live line charts for all four sensors with 20-point rolling window
  • ✔Configurable alert thresholds with toast notifications and alarm sound
  • ✔Persistent alerts log with filter by severity and CSV export
  • ✔Historical data viewer with date range filter and 2×2 chart layout
  • ✔Timestamps decoded from Firebase push keys — no firmware changes needed
  • ✔HX711 calibration tool with live weight readout
  • ✔Device online/offline status detection
  • ✔Dark / light theme with localStorage persistence
  • ✔Fully responsive — works on desktop, tablet, and mobile
